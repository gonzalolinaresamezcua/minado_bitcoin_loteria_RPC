# Python Bitcoinマイナー (RPC)

このスクリプトは、RPC (リモートプロシージャコール) を介してBitcoinノードと対話するPythonベースのBitcoinマイナーです。ブロックテンプレートの取得、コインベーストランザクションの構築、マークルルートの計算、ハッシュ処理 (プルーフオブワーク) の実行など、Bitcoinマイニングのプロセスを実証することを目的とした教育用に設計されています。

**免責事項:** このマイナーは、教育およびテスト目的 (例: RegTestまたはTestnet) を対象としています。Bitcoinネットワークの難易度が非常に高いため、このスクリプトを使用してメインネットで収益を上げてBitcoinをマイニングすることは不可能です。

## 特徴

*   RPCを使用してBitcoinノードに接続します。
*   ノードから実際のブロックテンプレートを取得します。
*   有効なコインベーストランザクションを構築します。
*   ブロック内のトランザクションのマークルルートを計算します。
*   有効なナンス (プルーフオブワーク) を見つけるためにSHA256ハッシュを実行します。
*   有効なブロックをBitcoinノードに送信します。
*   連続マイニングモード: ナンス範囲が使い果たされるかブロックが見つかった後、自動的に新しいテンプレートを取得してマイニングを続行します。
*   設定可能なナンス範囲とRPC接続パラメータ。
*   接続性とブロック構築を検証するために、定期的に「チェック」ブロックをノードに送信します (有効なPoWソリューションでない場合でも)。

## 要件

*   Python 3.6以降。
*   RPC経由でアクセス可能な実行中のBitcoinノード (例: Bitcoin Core)。
    *   TestnetまたはMainnetに接続する場合は、Bitcoinノードが完全に同期されていることを確認してください。RegTestの場合、これは問題ありません。
*   `requests` Pythonライブラリ。

## セットアップとインストール

1.  **リポジトリをクローンするか、ファイルをダウンロードします。**
    ```bash
    # gitがインストールされている場合
    # git clone <リポジトリURL>
    # cd <リポジトリディレクトリ>
    ```

2.  **依存関係をインストールします:**
    `requirements.txt`ファイルが含まれるディレクトリに移動し、次を実行します:
    ```bash
    pip install -r requirements.txt
    ```

3.  **BitcoinノードRPCを設定します:**
    RPC接続を許可するようにBitcoinノードを設定する必要があります。これには通常、`bitcoin.conf`ファイルで`rpcuser`と`rpcpassword`を設定することが含まれます。例:
    ```
    rpcuser=your_rpc_user
    rpcpassword=your_strong_rpc_password
    server=1
    txindex=1 # 一部のRPC呼び出しに推奨されますが、このスクリプトのコア機能には必ずしも必要ではありません。
    ```
    `bitcoin.conf`を変更した後は、Bitcoinノードを再起動することを忘れないでください。

4.  **マイナースクリプトを設定します:**
    `bitcoin_miner.py`ファイルを開き、スクリプトの先頭にある次のRPC設定変数を変更します:

    ```python
    # === Configuración ===
    RPC_USER = "usuario"  # BitcoinノードのRPCユーザー名に置き換えます
    RPC_PASSWORD = "constraseña"  # BitcoinノードのRPCパスワードに置き換えます
    RPC_PORT = 8332  # Mainnetのデフォルト。Testnet: 18332, Regtest: 18443
    RPC_URL = f"http://{RPC_USER}:{RPC_PASSWORD}@127.0.0.1:{RPC_PORT}/"
    ```
    -   `RPC_USER`: `bitcoin.conf`で設定したRPCユーザー名。
    -   `RPC_PASSWORD`: `bitcoin.conf`で設定したRPCパスワード。
    -   `RPC_PORT`: BitcoinノードのRPCポート。
        *   Mainnet: `8332`
        *   Testnet: `18332`
        *   Regtest: `18443`
    -   `RPC_URL`はこれらの値から自動的に構築されます。ノードが別のホストで実行されている場合は、`127.0.0.1`が正しいことを確認してください。

    `ENVIO_CADA_NONCES`変数も調整できます:
    ```python
    # Configuración de minado
    ENVIO_CADA_NONCES = 1000000  # Enviar bloque de comprobación cada 1 millón de nonces
    ```
    これは、マイニング中に「チェック」ブロックがノードに送信される頻度を制御します。

## 実行方法

1.  Bitcoinノードが実行されており、`bitcoin_miner.py`に正しいRPC認証情報とポートが設定されていることを確認します。

2.  ターミナルまたはコマンドプロンプトを開き、`bitcoin_miner.py`があるディレクトリに移動します。

3.  Pythonを使用してスクリプトを実行します:
    ```bash
    python bitcoin_miner.py
    ```

4.  **初期設定:**
    スクリプトは「連続モード」で起動し、初期ナンス範囲の設定を求められます:
    ```
    💡 MODO CONTINUO ACTIVADO
    🔄 El minero reiniciará automáticamente al completar cada rango
    📝 Configuración por defecto:
       • Nonce inicio: 0
       • Nonce fin: 4294967295
       • Rango total: 4,294,967,296 nonces

    ❓ ¿Usar configuración por defecto? (Enter=sí, 'n'=configurar manualmente):
    ```
    *   デフォルトのフルナンス範囲 (0から2^32 - 1) を使用するには、`Enter`を押します。
    *   カスタムの開始ナンスと終了ナンスを指定するには、`n`と入力して`Enter`を押します。

5.  その後、マイナーはBitcoinノードへの接続、ブロックテンプレートの取得、マイニングプロセスの開始を試みます。進行状況、ハッシュレート、見つかったまたは送信されたブロックを示す出力メッセージが表示されます。

6.  **マイナーの停止:**
    `Ctrl+C`を押してマイナーを中断します。連続モードでは、停止の確認を求められます:
    ```
    [⚠️] INTERRUPCIÓN DETECTADA EN CICLO #X
    🔄 El minero está en MODO CONTINUO

    ❓ ¿Realmente quieres DETENER el minado continuo? (escribe 'DETENER' para confirmar):
    ```
    スクリプトを停止するには、`DETENER`と入力して`Enter`を押します。そうしないと、マイニングが再開されます。

## 重要事項

*   **教育目的のみ:** このスクリプトは、Bitcoinマイニングプロセスについて学ぶためのものです。パフォーマンスは最適化されておらず、グローバルなハッシュパワーが膨大であるため、Bitcoinメインネットまたはパブリックテストネットでブロックを見つける可能性は非常に低いです。
*   **Bitcoinノードが必要:** RPC経由でアクセス可能な実行中のBitcoinノード (Bitcoin Coreなど) が必要です。このスクリプトはスタンドアロンでは動作しません。
*   **Regtest推奨:** テストと実験には、`regtest` (リグレッションテスト) モードでBitcoinノードに対してこのマイナーを実行することを強くお勧めします。`regtest`モードでは、ブロックを即座に生成し、プライベートテスト環境を作成できます。
*   **RPCセキュリティ:** BitcoinノードへのRPCアクセスには注意してください。特に、実際の資金を保持している場合は注意が必要です。`rpcpassword`が強力であることを確認し、RPCポートへのアクセスを制限するファイアウォールルールを検討してください。
*   **エラー処理:** スクリプトには、RPC呼び出しと接続の問題に対する基本的なエラー処理が含まれていますが、考えられるすべてのシナリオをカバーしているわけではありません。

## 仕組み (概要)

1.  **ブロックテンプレートの取得 (`getblocktemplate` RPC):** マイナーはBitcoinノードにブロックテンプレートを要求します。このテンプレートには、前のブロックに関する情報、含めるトランザクション、現在の難易度 (`bits`)、およびその他の必要なデータが含まれています。
2.  **Coinbaseトランザクションの構築:** 特別な「コインベース」トランザクションが作成されます。このトランザクションには、マイニング報酬とトランザクション手数料が含まれます。これは新しいブロックの最初のトランザクションです。
3.  **マークルルートの計算:** すべてのトランザクション (コインベース + テンプレートからのその他) のハッシュがマークルツリーに配置され、このツリーのルートが計算されます。マークルルートは、ブロック内のすべてのトランザクションを効率的に要約します。
4.  **ブロックヘッダーの構築:** ブロックヘッダーは次を使用して組み立てられます:
    *   バージョン
    *   前のブロックのハッシュ
    *   マークルルート
    *   タイムスタンプ
    *   ビット (難易度ターゲット)
    *   ナンス (マイナーが反復処理する値)
5.  **プルーフオブワーク (ハッシュ):** マイナーは、ブロックヘッダーに対して繰り返しダブルSHA256ハッシュを実行し、毎回`nonce`値を変更します。
6.  **ターゲットとの比較:** 結果のハッシュは整数に変換され、「ターゲット」難易度 (`bits`から派生) と比較されます。ハッシュがターゲット以下の場合、有効なブロックが見つかります。
7.  **ブロックの送信 (`submitblock` RPC):** 有効なナンスが見つかった場合、完全なブロック (ヘッダー + トランザクション) がBitcoinノードに送信されます。ノードがそれを受け入れると、ブロックはネットワークにブロードキャストされます。

このスクリプトは、これらのステップを連続ループで自動化します。
